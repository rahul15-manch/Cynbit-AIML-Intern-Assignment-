### 5. Beginner-Friendly Explanation
Imagine you have a list of numbers and you need to find two numbers that add up to a specific target. Instead of checking every possible pair (which is slow), this code uses a clever trick:

1. **Keep a "Memory" (Dictionary):** As you go through the list one number at a time, you remember each number and its position in a dictionary called `seen`.
2. **Check for the "Missing Piece":** For each number, you calculate what other number you would need to reach the target (`needed = target - number`).
3. **Look Up the Missing Piece:** You check if that `needed` number is already in your `seen` dictionary.
   - **If yes:** You found the pair! You return the index of the `needed` number (from the dictionary) and the current index.
   - **If no:** You add the current number and its index to the `seen` dictionary and move to the next number.

This approach is efficient because it only goes through the list once, making it much faster than checking every pair individually.
